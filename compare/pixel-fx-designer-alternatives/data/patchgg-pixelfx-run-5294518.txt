Not to be confused with the pixelfx_*.mjs / pixelfx_check.py files in this folder: those are Pixelbolt's own scripts,
written for this page on 19 October and 15 November, after Pixelbolt had its current name. Everything about patch-gg's pixelfx here starts "patchgg-pixelfx".

What we ran: pixelfx at commit 5294518ce7c72e48b6100a744596e0acf57f2826 (12 November 2026, "Link pixelfx's page on
Patch (#13)", the newest commit on main on 17 November; no tags or releases; package.json says 0.3.1). Six of its 244
effects, with each effect's own default settings (size, duration, 30 fps, seed): fire/campfire, explosions/smoke-bomb,
explosions/big-explosion, water/splash, lightning/lightning-strike, arcane/portal. No AI agent or language model was
involved, and Patch's command line (pch) was not installed or run.

Why it qualified to run (our rules for running another tool): open source (MIT) from its official repository;
src/ (library and effects) imports only its own relative modules, with no fetch, http, child_process, WebGL/WebGPU,
canvas, Math.random, Date, process or globalThis; tools/render.mjs and tools/lib/fxlib.mjs use node:fs, node:path,
node:url and node:child_process, whose one use is spawnSync("ffmpeg") for --gif/--mp4 previews (raw frames piped to a
local ffmpeg); tools/lib/png.mjs uses node:zlib. package.json has no install scripts and one devDependency (esbuild, for
building the gallery); we ran no npm install. tools/serve.mjs (a local HTTP server for the gallery) was not run.

Measure (from a folder holding the scripts and the clone; each work folder must not exist yet):
  python -I patchgg-pixelfx_measure.py src patchgg-pixelfx_frames.mjs run patchgg-pixelfx-effects-5294518.json
That runs, for each effect, twice, each in a new folder and new processes, and times each whole command:
  node src/tools/render.mjs <id> --sheet --out <run>/sheet     pixelfx's documented sprite-sheet export
  node src/tools/render.mjs <id> --gif --out <run>/gif         its GIF preview, made through ffmpeg
  node patchgg-pixelfx_frames.mjs src <id> <run>/frames        ours: pixelfx's loadEffect, renderFrames and encodePNG,
                                                               one RGBA PNG per frame (the image its sheet is built from)
then decodes everything with Pillow, and runs each effect once more with --opts {"palette": [4 or 5 PICO-8 colours]}.
  python -I patchgg-pixelfx_timing.py src run-timing patchgg-pixelfx-timing-5294518.json
  python -I patchgg-pixelfx_light0.py src patchgg-pixelfx_frames.mjs run-light0 patchgg-pixelfx-light0-5294518.json
  PLAYWRIGHT_MODULE=<playwright>/index.mjs CHROMIUM_EXE=<chromium-1248 chrome.exe> FIREFOX_EXE=<firefox-1555 firefox.exe>
    node patchgg-pixelfx_engines.mjs src patchgg-pixelfx-engines-5294518.json
