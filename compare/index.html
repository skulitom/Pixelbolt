Pixelbolt comparisons

We make Pixelbolt, a free, MIT-licensed pixel art toolkit with a local MCP server, a command line and a browser studio. These pages compare it with pixel art and sprite MCP servers for AI agents, and with alternatives to Pixel FX Designer for pixel-art effects. Each says which numbers we measured and which we read from the other tools' docs, and when it was last checked.

Pixel art and sprite MCP servers for AI agents: 7 compared

Checked 17 October 2026, refreshed 29 October. aseprite-mcp and pixel-mcp drive the paid Aseprite editor, SpriteCook and pixelforge-mcp generate images with hosted AI models, pixscii and pixelart-mcp draw on canvases on your machine, and Pixelbolt renders editable JSON recipes on your machine with no paid app, account, API key or image model. We read the other six from their code and docs without running them. We measured Pixelbolt 0.9.2, as installed from npm, on one Windows machine: all 19 of its plain example recipes rendered twice to byte-identical files, and a one-pixel fix over MCP changed exactly 1 pixel in 1 of 6 frames.

Pixel FX Designer alternatives for pixel-art fire, smoke, explosions and water: 8 tools compared

Checked 19 October 2026; Pixel VFX Forge added 27 October. The eight are Pixel FX Designer, SpriteMancer, Fluid FX, Pixel Composer, PHOSPHOR, BlastFX, Pixel VFX Forge and Pixelbolt. Of the seven alternatives to Pixel FX Designer, all but BlastFX and Pixel VFX Forge run a fluid or material simulation for smoke, fire or liquids, which Pixel FX Designer does not; Pixel VFX Forge stacks stylised layers such as slashes, beams and shockwaves instead. Pixelbolt is the only one of the eight with an MCP server that makes the effects. Measured on one Windows PC, its 0.9.0 release compiled each of its 10 effect presets three times to byte-identical files. We read the other seven tools' pages and docs without running them, so the only measured numbers are Pixelbolt's.
