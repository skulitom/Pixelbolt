Pixelbolt

Pixelbolt playground

Pixelbolt turns JSON recipes into pixel art, animations and effects. Pick an example, edit its recipe and watch the pixels change, then download a PNG, GIF or atlas, or copy a link that reopens it. Drop a recipe or a playground PNG anywhere here to open it.

For the CLI, MCP server and Studio, get Pixelbolt on GitHub.

Links allow 16,384 characters. For larger recipes, share a recipe file or a playground PNG.
