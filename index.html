Pixelbolt: pixel art and sprite animation for AI agents

Pixelbolt is a pixel art toolkit with a local MCP server, a command line and a browser studio. An agent such as Claude, Codex or Cursor writes an editable JSON recipe; Pixelbolt renders it to transparent PNG sprite sheets, texture atlases, animated PNGs, GIFs and numbered frames for a video editor, and the same recipe gives the same files every time. The agent can read every pixel back and fix one pixel or one frame without redrawing the rest. It is free and MIT-licensed, needs only Node.js 20 or newer, and uses no image model, API key or network service.
